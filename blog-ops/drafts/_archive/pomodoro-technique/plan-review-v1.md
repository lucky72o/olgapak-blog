## Revision instruction (verbatim, for the editor)

Apply these two changes to `plan.md` before advancing to the outline stage:

1. In `## Length target`, remove Verywell Mind from the "real content competitors on page 1" list (it is rank 7, and `research/serp.md` states ranks 7-15 are page-2 organic). Then either lower the target to 1,800-2,200 words, or keep 2,000-2,400 and add an explicit line justifying the gap against the corrected page-1 median, naming which H2s absorb the extra length and why.

2. In `## External links planned`, before treating 3 sources as final, verify `https://pmc.ncbi.nlm.nih.gov/articles/PMC6406620/` (from `research/serp.md` §"Citations harvested from competitors," classified `primary_source`, backing ADHD/learning-disability coping-strategy claims relevant to planned H2 6). If it verifies, add it as a 4th row in the external-links table anchored to H2 6 and add the supporting fact to `facts.md`. If it does not verify, add an explicit entry to `facts.md` §Rejected documenting why, alongside the existing NICHD and Wiley DOI rejections.

Minor, non-blocking: reconsider naming Email Generator alongside Text Summarizer in `## Product references planned` (brief.md names only Text Summarizer for this post), and add one clause to the "Forbidden" note in `## External links planned` clarifying that the PMC link is an allowlist exception rather than an oversight.
